# 로컬 실시간 받아쓰기 (Whisper STT)

마이크로 말하면 실시간으로 텍스트를 받아적는 데스크톱 앱입니다.
**인터넷 연결 없이 내 PC에서만** 동작하고, 음성이 외부로 전송되지 않습니다.
(모델을 처음 내려받을 때만 인터넷이 필요합니다.)

## 실행

`STT 실행.bat` 더블클릭 → 마이크 선택 → **▶ 받아쓰기 시작**

처음 한 번은 모델을 내려받느라 몇 분 걸립니다. 그 다음부터는 바로 시작됩니다.
문제가 생겨 원인을 보고 싶으면 `STT 실행(콘솔).bat` 으로 실행하세요.

다른 PC에 옮겼을 때는 `최초 설치.bat` 을 먼저 한 번 실행합니다.

## 화면 설명

| 항목 | 설명 |
|---|---|
| **모델** | 클수록 정확하고 반응이 느립니다. 아래 표 참고 |
| **언어** | 한국어 고정이 자동 감지보다 정확합니다 |
| **마이크** | 장치를 바꿨으면 `새로고침` |
| **감지 민감도** | 주변 소음보다 몇 dB 커야 "말"로 볼지. 값이 **작을수록 민감** |
| **문장 끊김 대기** | 이만큼 조용하면 한 문장이 끝난 것으로 보고 변환 |
| **입력 레벨** | 말할 때 막대가 **초록색**이면 정상 인식 중 |
| **말하는 중 미리보기** | 말하는 도중 회색 글씨로 임시 결과를 먼저 보여줌 (아래 설명) |

## 받아쓴 내용 다루기

본문은 **언제든 직접 편집할 수 있습니다.** 받아쓰기가 돌아가는 중에도 오타를
고치거나 문장을 지울 수 있고, 새로 도착한 문장이 편집 내용을 건드리지 않습니다.

| 버튼 | 단축키 | 설명 |
|---|---|---|
| **전체 복사** | Ctrl+Shift+C | 본문 전체를 클립보드로 (**시각 제외**) |
| **저장** | Ctrl+S | txt 파일로 저장 (시각 포함) |
| **되돌리기** | Ctrl+Z | 편집·받아쓴 문장 모두 되돌림 |
| **다시 실행** | Ctrl+Y | 되돌린 것을 복원 |
| **모두 지우기** | — | 본문 비우기 (Ctrl+Z 로 복구 가능) |

**복사에는 `[12:34:56]` 같은 시각이 빠집니다** — 다른 문서에 붙여넣기 좋게
문장만 넘어갑니다. 파일 저장은 기록용이므로 시각을 그대로 유지합니다.
시각 자체가 필요 없으면 `시각 표시` 체크를 끄면 화면·저장 모두에서 사라집니다.

일부만 복사하려면 마우스로 선택한 뒤 Ctrl+C 를 쓰면 됩니다. 이때는 선택한
그대로(시각 포함) 복사됩니다.

설정은 종료 시 `settings.json` 에 자동 저장됩니다.

### 편집 중 방해받지 않습니다

- 위쪽을 보며 편집하는 중에는 새 문장이 와도 **화면이 끌려가지 않습니다**
  (맨 아래를 보고 있을 때만 따라갑니다)
- 회색 미리보기는 본문이 아니라 **본문 아래 별도 영역**에 표시되므로,
  편집한 글자가 미리보기와 섞여 지워질 일이 없습니다

## 동작 방식

```
                          ┌─► small 모델 (미리보기) ──► 회색 글씨로 즉시 표시
마이크 ─► 무음 감지(VAD) ─┤        · 말하는 도중 2초마다
                          └─► 본 모델 (확정)      ──► 회색을 지우고 검은 글씨로 교체
                                   · 말이 끝난 뒤 한 번
```

**두 모델이 동시에 돕니다.** 말하는 도중에는 작은 `small` 모델이 2초마다
지금까지의 말을 회색 글씨로 먼저 띄우고, 말을 마치면 본 모델이 문장 전체를
정확하게 다시 읽어 검은 글씨로 교체합니다.

- 본문 아래 회색 영역 = 임시 결과. 틀릴 수 있고 저장/복사에 포함되지 않습니다
- 본문 = 확정 결과. 본 모델이 문장 전체를 보고 낸 답이며, 직접 편집할 수 있습니다

13.5초짜리 문장으로 실측한 결과, **첫 글자가 말 끝나기 10.4초 전**에 떴습니다.
확정본의 정확도는 미리보기를 켜기 전과 같습니다 (동시 실행 비용 약 0.24초).

미리보기가 거슬리면 `말하는 중 미리보기` 체크를 끄면 됩니다 (회색 영역도 사라집니다).

## 모델 고르기 (이 PC에서 실측)

GPU가 AMD(RX 9060 XT)라 CUDA를 못 써서 **CPU(int8)로 추론**합니다.
Ryzen 5 7600 기준 실측값:

| 모델 | 말 멈춘 뒤 표시까지 | 디스크 | 비고 |
|---|---|---|---|
| `small` | **1.1초** | 0.5GB | 가장 빠름. 짧은 메모·받아쓰기에 적합 |
| `medium` | **2.8초** | 1.5GB | 절충안 |
| `large-v3-turbo` | **4.3초** | 1.6GB | 기본값. 정확도 우선 |
| `large-v3` | 6초+ | 3.1GB | 가장 정확하지만 실시간엔 버거움 |

### 왜 짧게 말해도 시간이 걸리나요?

Whisper 인코더는 **조각 길이와 상관없이 항상 30초 분량을 처리**합니다.
그래서 1초를 말하든 15초를 말하든 변환 시간이 거의 같습니다(위 표의 값).

실질적인 의미:

- **짧게 끊어 말하면** 매번 그 시간을 다 씁니다 → 반응이 느리게 느껴짐
- **길게 이어 말하면** 한 번에 처리돼 훨씬 효율적입니다
  (`large-v3-turbo` 로 15초를 말하면 4.7초에 변환 = 실시간의 3배 속도)

즉 **끊어 말할수록 불리합니다.** 빠른 반응이 중요하면 `small` 이나 `medium` 으로,
정확도가 중요하면 `large-v3-turbo` 로 쓰세요.

말이 밀리기 시작하면 상태바에 `변환 대기 N개` 가 쌓입니다.
이 숫자가 계속 늘면 모델을 한 단계 낮추세요.
(본 모델은 `num_workers=2` 로 두 조각을 동시에 처리하므로 실측 처리량이 1.49배입니다.)

## 모델 미리 받기

```
.venv\Scripts\python.exe download_model.py              # 기본 모델
.venv\Scripts\python.exe download_model.py large-v3     # 특정 모델
.venv\Scripts\python.exe download_model.py --all        # 전부
```

모델은 `models/hf` 안에 저장됩니다. 지우면 다음 실행 때 다시 받습니다.

## 문제 해결

**말해도 막대가 안 움직여요** — 마이크 선택이 틀렸습니다. `새로고침` 후 다른 장치를 골라보세요.
Windows `설정 → 개인 정보 → 마이크` 에서 앱 접근이 허용돼 있는지도 확인하세요.

**막대는 움직이는데 텍스트가 안 나와요** — 막대가 파란색에 머물면 "말"로 인정되지 않은 것입니다.
`감지 민감도`를 낮춰(4~8 dB) 보세요.

**짧은 말이 잘려요 / 한 문장이 두 줄로 쪼개져요** — `문장 끊김 대기`를 1.2~1.5초로 늘리세요.

**회색 글씨가 최종 결과와 많이 달라요** — 정상입니다. 회색은 작은 모델의 임시 추측이고,
검은 글씨로 바뀐 것이 진짜 결과입니다. 회색이 신경 쓰이면 체크를 끄세요.
`settings.json` 의 `interim_model` 을 `medium` 으로 바꾸면 미리보기도 정확해지지만
반응이 느려지고 본 모델의 변환도 같이 느려집니다.

**엉뚱한 문장("시청해주셔서 감사합니다" 등)이 나와요** — Whisper가 무음에서 흔히 내는 환각입니다.
기본으로 걸러내지만 계속 나오면 `감지 민감도`를 올려 잡음이 덜 들어가게 하세요.
